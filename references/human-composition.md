# 人物的惊喜感、戏剧感与乱中秩序

本指南由《错位》扫描材料的构图研究推导；页号是素材文件名，不代表已核实的作品地点或拍摄年份。它描述可见结构，不断言摄影师现场如何安排、等待或拍摄。

## 构图目标

人物行为像生活，图像关系有选择。戏剧感可来自看与被看、快与慢、巨与小、露与藏、身体与图形，而无须表情夸张或故事冲突。“乱而有序”允许信息丰富，但把丰富信息组织成少数形状、区域和观看节奏。

画面需要具体的观看内容，不要求一律靠第二眼巧合。精选的 23 张样例同时认可安静生活、直接视觉笑点与人物互动，见 [core-photography.md](core-photography.md)。泳池的近头远脚靠方向与尺度相连；茶馆的举杯转头、近处桌面和后方生活节奏同样成立。删减检查针对视觉、空间和生活作用，不要求每个人都推进剧情，也不清除全部偶然背景。

## 如何得到“有序”

- **轮廓能分开**：头部与手势旁留下能辨认的背景缝隙；有意遮挡可以很大胆，但意外粘连、头上长物件和无理由切手要修正。
- **尺度不平均**：近、中、远的身体大小、完整程度和亮度可以显著不同；不把三个人均匀排成三层样板。
- **几何先成立**：用真实墙角、栏杆、台阶、窗框或影子组织画面，人物在这些结构中交会。不要给复杂画面堆更多小道具。
- **观看有先后与回路**：先看到一个强形，再发现第二个动作或面孔，随后回看前景；不需要唯一清楚完整的主人公。
- **边缘有信息**：半身、鞋、手可以从画外进入，让事件似乎继续到画外。裁切应产生关系与张力，不是随机截断。
- **时机按场景判断**：瞬间型画面可以捕捉手将要挡脸、两种动作将要相遇或脚刚抬起；静态型则看神态、视线、空间与动作停顿是否具体。“换半步或半秒”适用于巧合和临界动作，不是所有照片的必要条件。

“三角形、三分法”不是必填项。优先描述具体形状如何接近、分离、重复或形成反向关系。

## 可执行简报

先写具体的观看发现，不先列人物岗位。只给几个人分配不同动作，即使写了“轮廓分开、动作反向、近中远景”，仍可能失去趣味。下面的简报用于识别关系，不是增加角色的填空表。

```text
哪些大形状先稳住画面，随后哪个身体局部、动作或空间关系值得回看？
这个发现为什么需要当前的机位、时刻、遮挡或观看方向？
人物和物件在动作、节奏、空间或生活状态上各起什么作用？哪些只是填充？
如何用场所的真实几何、光色与必要间隙，让关系可读且仍有余味？
与本组其他图相比，本张的观看关系是否真正不同，而不只是换题材？
```

轮廓分开与空间连通是阅读条件；身体方向相反本身不保证戏剧性。理发店样例的关键是红布隐藏实体面孔，镜子又把同一张脸交还给观看者；球场样例的近处弯臂改变了远处投篮动作的尺度与观看入口。不能只学成一人挥布、一人坐着、第三人路过，或一人抬手、一人跳起、第三人弯腰。

删除和替换只是辅助判断：检查次要人物是否贡献动作联系、节奏、尺度、空间或具体生活状态，而不只检查他是否改变主笑点。完全没有这些作用时再删减，不设人数上限。不能为了让每个人都推进剧情，把大家安排成合谋完成一个视觉谜题；也不排斥用户已认可的直接互动与好懂的笑点。

可用示意：“近处工人抬起空心窗框，框内一位更远的人恰好侧身经过；框的边角与肩之间留细缝，另一只手仍能解释抬框动作，远处门框把旁人的动作隔开。”此为关系模板，需换成适合当前场景的原创内容，不强制照抄。

## 审查与纠偏

1. 去掉地点名、颜色形容词和标题后，仍能说出一个具体视觉事件吗？
2. 前景真的改变了人物关系，还是随便放进一个篮子、肩膀或红物件？
3. 背景的人有可读作用，还是只是证明街上有人？
4. 遮挡保留了物理来源和必要识别线索吗？各个身体能区分吗？
5. 复杂画面是否由少数大形稳定下来？有没有所有细节都同样亮、同样完整？
6. 人物是否显得在为一个寓意摆姿？若是，保留关系但减去表演、对称和过分精准的重复。

清晰锐利不等于所有平面同样锐利，主体动作可以有少量真实运动痕迹；通透不等于填亮全部阴影。保留这些差异才能让戏剧性与摄影真实性共存。

## 换题材时的保留项

23 张精选样例同时包含横幅、竖幅、日常与虚构场景，见 [approved-visual-examples.md](approved-visual-examples.md)。结合强近景、自然动作与可读的中远景关系，从 24–28mm 视角起步。延续风格时保留这些关系，用户另行指定的摄影类型与画幅优先。

- **从现场与视点组织关系**：先确定相机在哪里、环境如何连通、人物正在做什么，再选择需要强调的交会。分界、遮挡和第二眼发现为场景服务，不先用“缝里找脸”的图形模板安排所有人。
- **情绪不能代替形式**：笑、拥抱、疲惫、裙摆飘动只是行为线索。至少说清本张里这些线索如何被机位、遮挡、动作时机或明暗联系起来。只有漂亮姿态与好看的光，仍可能偏离本风格。
- **完整程度按关系决定**：全身、半身、局部和深暗区都可参与构图。不要求全员露全，也不要求主角缺头或藏脸。球场弯臂、理发红布等正向样例允许强烈的大前景；要学的是它与后方动作、镜面或街道的组织关系，不按占幅大小判好坏。人数、遮挡面积和近远层数不设配额。
- **复杂度来自相互作用**：多个动作可各自发生，但要在当前视点产生具体的轮廓接近、方向抵触、尺度压力或观看回路。不要为增加层次随意添一个背景人。
- **允许不同强度的趣味**：空裤腿与倒立、巨影和高跷等直接的视觉幽默已在认可样例中；安静的茶馆、写字和烘焙也在。按场景选择，不把含蓄当成排斥笑点的理由，也不把全部图片变成同一种视觉谜题。

参考感被用户明确否定后，回看已明确对应文件的正向样例与少量原始画册照片，先判断偏差。需要视觉参考输入时再选对应图，并明确其角色；传入参考图本身不能证明结果更接近。仅借空间组织、动作关系与光色逻辑，不把同一个局部遮挡布局套给所有题材，不复制人脸、地点、扫描旧化、边框或水印。保留当前鲜明通透的成像要求。不要把整本画册或总览缩略图直接当成参考输入。

理发店让红布的遮挡、镜中的面孔与路人的转头同处一幅；球场让近处弯臂、后方跃起与右侧俯身互相牵动；渡口让大救生圈、蓝栏杆、登船动作和水面共同建立纵深。这些是具体正向样例，不是强制复刻的道具清单。24–28mm 的应用见 [wide-angle-space.md](wide-angle-space.md)。

交付前问：注意力先落在哪里，具体的动作、神态或空间为什么值得看，形式怎样支持它？巧合型再检查第二眼如何成立。若只能回答题材或情绪标签，继续修改构图。不能仅因肤色、锐度和配色合格就宣布纠偏成功；审阅文字需区分已经看见的改进和仍待用户判断的参考接近程度。
