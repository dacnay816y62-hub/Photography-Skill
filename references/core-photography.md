# 当前核心：从 23 张明确认可的照片提炼方法

以 23 张精选 AI 摄影作品作为视觉校准依据。对应关系见 [原图索引](approved-visual-examples.md)，完整观察见 [统一分析](approved-23-analysis.md)。评价针对每张图的具体构图与观看关系，不以题材或批次替代判断。

**用身处事件中的视点，把具体的人物状态、近处形状与可读环境组织起来；让设计感、临场感和趣味在同一张照片里成立。**

## 稳定保留什么

1. **视点有参与感。** 相机可以在桌边、水线、车门内或工作物旁；手、身体和器物与观看者有明确距离。先选机位，再选焦距，不能靠写上 24mm 获得临场感。
2. **近处形状在做事。** 搬运物、手臂、托盘、纸和窗框来自具体活动；它们能引导观看、分区或改变人物显露。也允许不使用大前景，或保留完整面孔。
3. **前后空间一起可读。** 门口、栏杆、玻璃、地面和光区使主体与环境连通。细节可多，但阅读层级、轮廓和大形状要清楚，不把背景全部虚化或堵成缝隙。
4. **人物状态具体。** 转头举杯、停笔望向门外、托盘经过门洞、上岸接茶，都是可见的状态；“有灵魂”“忙碌”“戏剧性”不能代替动作和神态。
5. **色彩与质感明净有力。** 有颜色的材质保留鲜明色度，肤色自然，中间调有光、黑位有重量。金属、织物、水、皮肤和玻璃各有解析；不要求处处等锐，也不固定红黄蓝。

## 三种都成立的创作路径

| 路径 | 认可样例 | 生成时重点 |
|---|---|---|
| 生活现场的张力 | P01 渡口、P02 茶馆、P07 写字、P15 面包房 | 机位距离、正在进行或暂时停下的动作、真实神态、物件与场所的连续关系。无需添加笑话或谜底。 |
| 视觉巧合与陌生化 | P03 蓝框、P04 弯臂、P05 红布、P08 椅架、P09 头与脚、P10 裤腿、P11 巨影、P12 金鱼、P13 高跷、P20 玻璃门 | 精确的尺度、方向、遮挡、镜像或反差；保留来源与识别线索。直接好懂的幽默也可以成立。 |
| 人物互动与动作交会 | P14 端茶、P17 登车、P19 手与猫爪、P21 抢肉、P22 挥扇与鸡翼、P23 递热茶 | 明确谁在做什么、动作朝向谁或什么、哪一段距离或时机产生张力；不要求夸张表情。 |

这些是选择工具，不是分类边界或系列配额；同一张可兼具多种关系。P06 水线泳者、P16 戏班与 P18 维修也可横跨路径。一次优先展开一个主要看点，辅助细节自然支持它。

## 避免把方法变成公式

- 人物可以各做各的事，也可以直接互动。背景的意义包括节奏、空间和生活状态，不能只用“是否推动同一剧情”决定去留。
- 惊喜可以是明确笑点、空间发现，也可以是一次动作停顿或微小关照。第二眼谜底、半秒巧合、遮脸和大前景都不是每张必填项。
- 静态不是随手拍，完整面孔不是摆拍。需要判断神态、距离、形状与观看方向是否经过选择。
- 摄影总纲独立于题材。历史、科幻、IP 与地域名仅用于样例定位，只有用户要求时才使用；不把这些测试写成默认世界观或自动添加角色。
- 用户指定虚构能力时允许相应设定，例如特殊身体能力；其余遮挡、接触、材质和光照仍需自洽。认可整体效果不代表认可每个光学或人体瑕疵。

## 执行顺序

看输入与保留项 → 选择主要观看路径 → 回看相关的 1–2 张原图 → 确定机位、近处形状与空间通路 → 写具体动作或神态 → 安排光色 → 生成并按该路径审阅。

24–28mm 是起始镜头方向；竖幅创作可从 3:4 起步，画幅仍按题材与用户要求决定。原作和已生成样例的真实焦距不可由外观反推。系列创作需改变观看关系，不能只替换地区、时代或职业。

交付判断同时检查：照片具体在看什么、构图怎样使它成立、成像是否鲜明通透。没有人文状态与观看内容时，漂亮质感不能单独算成功；安静照片也不必硬补视觉噱头。
