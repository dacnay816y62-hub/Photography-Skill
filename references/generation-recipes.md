# 两种入口的生成方法

先读用户输入，再选择这里的流程，并应用 [rendering-dna.md](rendering-dna.md) 的清晰、锐利、通透与鲜明色彩标准。模板是组织提示词的辅助，不要求逐项填满，也不应把所有示例元素复制进成片。

## 提示词 → 新摄影作品

信息足够且用户要求生成时直接执行；用户要求先更新技能时不生成。用户只说“雨天街口，有灵魂”，可补足一个与场景自然相关的动作和关系；用户已经指定人物、时间、地点、构图时，保留这些选择。默认一张完整照片，画幅沿用用户最近明确要求，未指定才根据题材选择。默认镜头方向按 [wide-angle-space.md](wide-angle-space.md) 在全画幅等效 24mm 与 28mm 中选定一个，落实机位、距离和环境关系。

内部先形成短简报，并回看 [core-photography.md](core-photography.md) 中与当前关系相近的原图。先判断画面是否有具体发现，再安排必要的人物；不要先把前、中、后景分别分配给一个人，然后用“反向动作”解释为戏剧感。可用一句自然语言说明：看见了什么，随后为什么愿意再看。若只能说“几个人各做不同的事”而说不出节奏、空间或具体的人物状态，先改构思。安静场景不强加巧合；已选样例里的直接视觉幽默也可以使用。

```text
稳定画面的大形状，以及身体、动作或空间之间值得回看的联系：
这个关系需要怎样的时刻、机位和距离：
人物、物件与场所怎样贡献动作、节奏或空间；哪些只是填充：
依附实体的光色与清晰通透成像：
主要看点属于生活现场、视觉巧合还是人物互动；不必三者齐全：
```

把简报转换为自然、连贯的图像指令。独立动作可以通过轮廓、方向、尺度、色块或空隙发生联系；直接互动与视觉笑点也是可选路径。只展开最适合这一张的主关系，不把所有人物安排成同一种机关。摄影师名称不是必要字段。可以用中文直接调用支持中文的工具，无需强制先翻译英文。

### 可调整的生成模板

```text
生成一张完整、可信的摄影作品，题材为【用户题材】。
【时空与天气】中，【主体】正在【具体且自然的动作】。
采用【当前适用的全画幅等效 24mm 或 28mm 视角；用户另有要求则遵从】，相机位于【实际位置、高度与距离】，画面以【构图关系】组织；通过【具体地面、通道、柜台或环境面】保留人物与场所的联系，【第二线索】与主体形成【视觉/情绪关系】。
【人物局部、物件或动作】在这个瞬间与【另一轮廓/动作】形成【具体交会】；保持【关键间隙或遮挡来源】可辨，以【真实几何或光区】分开事件。按题材需要使用，不能为填模板硬加人物。
【主光源与遮挡】让【区域】明亮、【区域】进入阴影；【实体色块】与【另一实体色块】构成色彩关系。
保留【材质、景深、适度运动痕迹】，让环境细节可信。照片像在一个真实瞬间被发现，关系含蓄，不要求人物表演情绪。
成像清晰锐利、空气通透，色彩鲜明有密度，真实肤色；中间调明亮、黑位干净、高光受控。焦内细节自然，不去饱和、不蒙灰，不产生锐化光晕。
【用户必须保留或避免的内容】。单幅照片，无书页、拼贴边框、额外标题或水印。
```

### 示例 A：雨后街口的等待

用户：“雨后一个人在街口等车，有点孤独。”

方向：等待与城市反射的错拍，使用玻璃与真实街道两个空间，不需要增加人群。

```text
生成一张全画幅等效 28mm 视角的街头摄影，画幅遵循用户当前要求。雨刚停，一个穿日常蓝外套的人在街角站牌旁等车，肩膀略松，视线落在画外即将来车的方向。相机站在公交亭侧面、距人物约两米处，取景保留人物、站亭与街道的连续空间；玻璃边缘划出较暗的倒影区域，同一个人的倒影只显出一部分轮廓，与真实身体有清楚的空间对应。湿路面延伸到画面深处，一辆远处车辆的暖灯在地面形成短而断续的反光。阴天柔光但曝光充足，蓝色衣料、暖色灯光与路面中性色干净分离，保留自然丰厚色度。空气清澈，皮肤与衣料细节锐利自然，玻璃反光清楚，中间调明亮、暗部有重量，无灰雾与褪色滤镜。情绪来自停住的人与仍在流动的街道，不添加眼泪、浓雾或夸张戏剧动作。真实摄影质感，单幅照片，无文字版式或水印。
```

### 示例 B：无人巷子的庆祝余韵

用户：“庆祝之后的空巷，安静但不要太悲伤。”

方向：缺席与遗留；从原书的物件关系迁移，不复刻气球原图。

```text
生成一张安静的日常摄影。小巷尽头的店刚关门，门边折叠椅上留着一顶用过的纸帽，一条短彩带缠在椅脚，巷子没有人。视点贴近日常站立高度，近处椅子占据一侧，另一侧留下通向远处窗光的狭长空间。墙面保持中性的材质色与细微旧痕，纸帽的红色与远处暖窗自然呼应，彩色物件保持丰厚色度。柔和的傍晚天光，影子边缘柔和，但纸张、金属与墙面细节清楚锐利。中间调有光，黑位扎实，空气通透，没有全图灰膜或棕色滤镜。物件重量、接触关系和透视可信。画面有聚会刚散的生活感与轻微幽默，不渲染灾难、废墟或恐怖。单幅摄影作品，无字幕。
```

## 已有照片 → 新摄影作品

### 查看与保留

先查看原图，写具体观察，不用“普通”“没有灵魂”评价用户。确认主体、动作、空间、现有光源与潜在的关系线索。将待改照片标为图 A；其他照片按身份参考或风格参考分别标记。

保留项优先包括用户点名内容；未指定时保留主角身份、主要物件与能辨认原场景的关键线索。不要仅因“二次生成”就换脸、换时代、换国家、增加陌生人。若用户明确要求彻底重构，则服从新的范围。

| 改变程度 | 可以做什么 | 应保留什么 |
|---|---|---|
| 轻度 | 适度裁切、光色组织、清晰度与材质微调；放大原有关系 | 人物、动作、空间和主要物件 |
| 适度，默认 | 重新安排取景、局部遮挡、光区与背景主次；必要时调整非关键细节 | 身份、核心事件、主要服装/物件、场所辨识线索 |
| 大幅，用户明确要求时 | 重建空间和动作关系、较大改变时间或环境，做同一主体的新作品 | 用户指定的身份与保留项 |

这不是菜单审批流程。用户已明确想法时直接选取适当强度；不强迫对方回答百分比。

### 使用原图已有的关系

原图有玻璃：考虑反射与透视的分离；不能任意把玻璃后的人复制到街上。

原图有人和墙：考虑人物与投影的相位、墙面图像或墙角空间；原本没有图像时优先用真实影子，不必添加海报。

原图是独处的人：保留独处，利用空椅、门洞、远景亮点或与环境的尺度关系，不强行加多人。

原图是干净室内或静物：可以转为家具边缘、窗景与生活痕迹的关系，不强制迁移到异国街头。

原图已有戏剧光：先检查动作与空间是否成立；不需要进一步增加饱和度。

### 编辑模板

```text
图 A 是唯一需要再创作的原照片。【图 B 如有：仅用于构图/光色参考，不能替换 A 的主体。】
保留 A 的【具体人物身份特征、服装、主物件、场所线索】。
在【用户允许的强度】内将照片重构为【具体创作方向】。
利用原图已有的【可见线索】，把【主体与第二线索】安排成【具体空间关系】；【视点/裁切/遮挡说明】。
光线【方向与边界】，色彩来自【原场景的实体】，材质维持摄影真实性。
依用户要求呈现清晰锐利、通透且色彩鲜明的成像：曝光充足的中间调、干净黑位、受控高光、清楚色相分离和真实肤色；天气、身份与必须保留项不因质感调整而改变。
情绪通过【动作、距离或缺席】体现，保留未被解释完的关系。
不能改变【关键保留项】。镜像与影子符合实体来源，局部遮挡有合理轮廓，无额外肢体。输出一张新照片，不含原参考的书页、扫描水印或文字版式。
```

### 示例 C：街边摊原图的适度重构

以下为条件示例，只有看见对应输入特征时才可使用，不能声称用户原图一定有这些内容。

假定原图：一个穿浅色衣服的摊主，绿色遮阳棚，金属秤，后方窄过道。

```text
对图 A 做适度摄影再创作。保留摊主的相貌、年龄感、浅色衣服、现有摊位和金属秤，不增加其他人物。调整取景，使秤盘靠近画面下缘形成前景，摊主的手仍与秤有清楚的操作关系，后方过道保留一小段可辨认的纵深。棚缘投下的阴影穿过柜台，摊主侧脸和手接触到自然侧光，脸部仍足以辨认。沿用原图绿色棚布、金属中性色与食材本色，呈现鲜明而有密度的表面色，肤色明净自然。中间调明亮，暗部干净扎实，空气通透；衣料、皮肤、菜叶和金属各有清楚锐利的自然细节，不蒙灰、不去饱和、不加锐化光晕。情绪来自一次工作动作尚未结束的停顿，不把摊主改成摆拍模特。透视和手部正确，单幅照片。
```

### 示例 D：保持一人、阴天与原地点

用户：“保留这个人和这里，别加人，不要硬光，但要更有错位感。”

决策：选原有门框、反光面或影像平面；若均不存在，用前景物件尺度与身体的局部遮挡。保留柔光与单人，不把风格规则置于用户约束之上。

## 系列与迭代

用户要多张时，每张改变一个主要观看关系或时刻，保持同一主体的识别线索。不要只变颜色。按用户数量分别生成，最后查看系列的一致性与变化。

用户自由随机选题时，场景、光照和情绪应有变化，不把整组默认成旧街、灰天和孤独，也不把国外视为更有质感。国内与国外都依具体生活、材料和光线组织；没有地点要求时可自然覆盖不同地域。

同一风格下的“不同方向”应改变生活场景、关系或光照，同时保留人物构图的张力；不可仅用不同题材的精美标准照凑成系列，也不可全组套用大身体挡住小人物的公式。简报先交代现场、机位与距离，再写具体交会和成像。用户反馈参考感消失时，回看 [已确认的视觉样例](approved-visual-examples.md) 及 [human-composition.md](human-composition.md) 的换题材纠偏，按实际需要使用图像参考。

系列提交前，把每张简报中的地点、服装和职业拿掉再比较。如果仍全是“近处举起物件、中间经过一人、后面一人弯腰”，关系没有变化，应在生图前重构。让每张的趣味来自具体场景里的发现；不以人数、动作数量、巨大背景或时代标签代替发现。用户刚否定模板化时，优先验证少量不同的关系，再扩成更多变体；用户明确给出的数量和题材仍优先。

生成失败时检查实际返回原因。可在已有授权内修正输入方式或冲突提示词；工具不可用、持续失败或需要另一个付费服务时如实说明，不伪造结果，不自动购买或无限调用。

修图追问示例：“太像广告片”→减掉过分整齐的人物姿态、无来源轮廓光与均匀精修；保留空间关系。“太乱”→减弱一个次事件或色块，不把所有背景抹成虚化。“没有情绪”→让动作和环境发生关系，不直接要求‘更悲伤’。
